## Úvod do jazyka C++

* Jazyk C vyvinul Dennis Ritchie v roku 1972 na podporu vývoja operačného systému Unix.
* Jazyk C++ vyvinul Bjarne Stroustrup v roku 1985 ako rozšírenie jazyka C s pridaním objektovo-orientovaného programovania.
* Obidva jazyky sa od svojho vzniku vyvíjali a rozširovali a existujú vo viacerých verziách.

* Na dnešnej prednáške si ukážeme niektoré rozdiely medzi C a C++, aby sme vedeli doteraz preberané programy prepísať do C++ a využiť aj niektoré črty, ktoré v C neexistujú.
* Z jazyka C++ však na tomto predmete uvidíme iba veľmi malú časť.
* Na predmete Programovanie (2) v Jave sa v jazyku Java naučíte objektovo orientované programovanie a ďalšie pokročilé techniky, ktoré sa si potom môžete naštudovať aj vo verzii z C++. C++ pravdepodobne stretnete aj na predmete Programovanie (3).

### Kompilovanie v jazyku C++

* Postupujeme podobne ako pri jazyku C, ale namiesto príkazu `gcc` používame príkaz `g++` a programu dáme príponu `.cpp` namiesto `.c`.
* Napríklad program `program.cpp` skompilujeme príkazom:
```bash
g++ program.cpp -o program
```

* Programy v jazyku C vieme buď priamo alebo po menších úpravách skompilovať aj v jazyku C++ kompilátorom `g++`. 
* V našich programoch hlavnou zmenou je, že musíme explicitne pretypovať návratovú hodnotu funkcie `malloc`.

```cpp
int *a = (int *)malloc(sizeof(int) * 10);
```

### Knižnice 

* V C++ fungujú štandardné knižnice, na ktoré sme zvyknutí z jazyka C.
* V príkaze `#include` sa ale namiesto prípony `.h` odporúča použiť názov s písmenom c, napr. `#include <cstdio>` namiesto `#include <stdio.h>`. 
* Pred názvy funkcií a premenných zo štandardných knižníc sa pridáva predpona `std::`.
* Tento konštrukt sa nazýva namespace a umožní nám rýchlo rozlíšiť, že funkcia pochádza zo štandardnej knižnice.

```cpp
#include <cstdio>
int main() {
    std::printf("Hello world!\n");
}
```

Jazyk C++ obsahuje aj ďalšie knižnice, ktoré v C neexistujú. Zopár ich uvidíme nižšie. 

### Bool a struct

V C++ sú `bool`, `true` a `false` rezervované slová, nemusíme používať knižnicu `stdbool`.

Pri definovaní štruktúr nemusíme používať kľúčové slovo `typedef`, názov typu píšeme hneď za `struct`.

```cpp
#include <cstdio>

struct bod {
    int x, y;
};

int main() {
    bod b = {1, 2};
    std::printf("x:%d, y:%d\n", b.x, b.y);
}
```

### Parametre odovzdávané referenciou

* V jazyku C sa parametre do funkcie odovzdávajú **hodnotou**, čo znamená, že sa vytvorí kópia premennej a ak ju zmeníme vo funkcii, zmena sa neprejaví mimo funkcie. 
* Toto platí aj smerníky, pretože smerník je len hodnota adresy, ktorá sa odovzdáva do funkcie. Ak zmeníme hodnotu samotného smerníka, zmena sa neprejaví mimo funkcie. Ak však zmeníme hodnotu, na ktorú smerník ukazuje, zmena sa prejaví aj mimo funkcie.
* Možno sa zdalo, že polia sú výnimka, ale pole je len smerník, takže platí bod vyššie.


Napríklad funkcia `swap` na zámenu hodnôt dvoch premenných pomocou smerníkov sa dá napísať v C aj C++.
```c
#include <stdio.h>
void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);
    printf("x:%d, y:%d\n", x, y);
}
```

* Do premennej `a` sme nakopírovali adresu premennej `x`.
* Ak by sme menili samotnú premennú `a` (príkazom typu `a = volaco`), zmena by sa neprejavila mimo funkcie. 
* Ale my sme zmenili hodnotu, na ktorú smerník `a` ukazuje, takže sa zmena prejavila aj mimo funkcie.

V C++ sa dajú parametre do funkcií odovzdávať aj **referenciou**, čo znamená, že parameter bude novým menom pre premennú, ktorá sa odovzdáva do funkcie. Ak zmeníme hodnotu parametra vo funkcii, zmena sa prejaví aj mimo funkcie.

```cpp
#include <cstdio>
void swap(int &a, int &b) {
    int tmp = a;
    a = b;
    b = tmp;
}
int main() {
    int x = 1, y = 2;
    swap(x, y);
    printf("x:%d, y:%d\n", x, y);
}
```

* Odovzdávanie referenciou zapíšeme pomocou znaku `&` pred názvom parametra vo funkcii.
* Napríklad parameter `a` bude v rámci funkcie `swap` novým menom pre premennú `x` z `main`.
* Bez použitia smerníkov je kód o niečo jednoduchší.

### Práca s pamäťou pomocou new a delete

* Funkcie `malloc` a `free` z jazyka C sa dajú používať aj v C++, ale nie je to obvyklé. 
* V C++ sa na alokáciu pamäte používajú operátory `new` a `delete`.

Ukážka alokácie a dealokácie pamäte pre jednu premennú a pole:
```cpp
int *p = new int; // alokuje pamäť pre jednu premennú typu int
delete p; // uvoľní pamäť

int *a = new int[10]; // alokuje pamäť pre pole 10 int-ov
delete[] a; // uvoľní pamäť pre pole
```

* Pozor, ak alokujeme pole, musíme použiť `delete[]`.
* V `malloc` sme museli spočítať veľkosť pamäte, v `new` uvedieme iba typ a počet prvkov poľa.

Alokácia a dealokácia matice:
```cpp
int ** vytvorMaticu(int m, int n) {
    /* Vytvorí a vráti maticu (obdĺžnikovú tabuľku)
     * s m riadkami a n stĺpcami. */
    int **a;
    a = new int *[m];
    for (int i = 0; i < m; i++) {
        a[i] = new int[n];
    }
    return a;
}

void zmazMaticu(int **a, int m) {
    /* Uvoľní z pamäte maticu s m riadkami. */
    for (int i = 0; i < m; i++) {
        delete[] a[i];
    }
    delete[] a;
}
```

### Vector

* Štandardná knižnica jazyka C++ obsahuje veľa [dátových
štruktúr](http://www.cplusplus.com/reference/stl/). 
* Ide o generické štruktúry, ktoré môžu uchovávať dáta rôznych typov. 
* Dátová štruktúra [`vector`](http://www.cplusplus.com/reference/vector/vector/) predstavuje dynamické pole, ktoré sa podľa potreby zväčšuje a zmenšuje. 
* Základ implementácie takéto poľa sme videli na [prednáške 14](https://dcs-fmph.github.io/prog1/notes/P14.html#aplik%C3%A1cia-smern%C3%ADkov-dynamick%C3%A9-polia).

```cpp
#include <vector>

std::vector<int> a;       // vytvorí pole celých čísel, 
                     // ktoré zatiaľ nemá žiadne prvky

std::vector<int> b(10);   // vytvorí pole 10 celých čísel, 
                     // všetky inicializuje na 0

std::vector<int> c(5, 1); // vytvorí pole 5 celých čísel, 
                     // ktoré inicializuje na 1
```

Typ `vector` je šablóna (template), takže môžeme vytvárať polia rôznych typov, napr. `vector<double>`, `vector<char *>` a pod.

Tri dôležité metódy/operácie s `vector`-mi:
- `a.size()` vráti počet prvkov v poli,
- `a.push_back(x)` vloží hodnotu `x` na koniec poľa, 
čím sa `a.size()` zväčší o 1. Podľa potreby pole realokuje a pod.
- `a[i]` pristupuje k prvku poľa `a` na indexe `i` podobne ako pri obyčajných poliach.

Nasledujúci program načítava čísla až po koniec vstupu, ukladá ich do vektora a potom ich vypíše na výstup.

```cpp
#include <vector>
#include <cstdio>

int main() {
    std::vector<int> a;  // vytvorí prázdny vektor celých čísel
    while(true) {
        // načítava čísla až po koniec vstupu
        int x;
        int ret = std::scanf("%d", &x);
        if (ret != 1) break;
        // vloží číslo x na koniec vektora
        a.push_back(x);
    }

    // vypíše všetky načítané čísla
    for (int i = 0; i < (int)a.size(); i++) {
        std::printf("%d\n", a[i]);
    }
}
```

Pretypovanie `(int)` pred `a.size()` uvádzame, aby sme predišli varovaniu kompilátora, že porovnávame číslo bez znamienka s typom `int`. 

### Matice pomocou vektorov

Maticu s `m` riadkami a `n` stĺpcami môžeme vytvoriť ako vektor vektorov.

```cpp
int m = 3, n = 4;
std::vector<std::vector<int>> a(m, std::vector<int>(n, 0));
```

* Premenná `a` je vektor, ktorý obsahuje `m` vektorov, pričom každý z týchto vektorov obsahuje `n` celých čísel, ktoré sú inicializované na 0.
* Ide o náhradu kódu `int **a = vytvorMaticu(m, n);` pričom nemusíme písať funkciu `vytvorMaticu`.
* Takúto maticu z vektorov nie je potrebné uvoľňovať z pamäte, po skončení funkcie, v ktorej je definovaná, sa automaticky uvoľní.

### Posielanie vektorov do funkcií, const

* Keď do funkcie posielame `struct` alebo zložitejší objekt, ako napríklad vector, je vhodné posielať ho **referenciou**, aby sa nevytvárala kópia objektu.
* V hlavičke funkcie sa parameter definuje napríklad ako `std::vector<int> &a`.
* Slovom `const` môžeme zabezpečiť, že parameter nebude modifikovaný v rámci funkcie.

Tu je napríklad funkcia, ktorá vypíše všetky prvky vektora celých čísel (nepotrebuje počet prvkov ako parameter, zistí ho pomocou `a.size()`).
```cpp
void vypis(const std::vector<int> &a) {
    for (int i = 0; i < a.size(); i++) {
        std::printf(" %d", a[i]);
    }
    std::printf("\n");
}
```

Ak ale napríklad chceme každú hodnotu vektora zväčšiť o 1, parameter nemôžeme definovať ako `const`, pretože ho budeme modifikovať.
```cpp
void zvys(std::vector<int> &a) {
    for (int i = 0; i < a.size(); i++) {
        a[i]++;
    }
}
```

Ešte na ukážku funkcia, ktorá vypíše maticu (vytvorenú ako vektor vektorov) celých čísel a jej veľkosť zistí pomocou `a.size()` a `a[i].size()`.

```cpp
void vypisMaticu(const std::vector<std::vector<int>> &a) {
    for (int i = 0; i < (int)a.size(); i++) {
        for (int j = 0; j < (int)a[i].size(); j++) {
            std::printf("%d ", a[i][j]);
        }
        std::printf("\n");
    }
}
```

#### Vstup a výstup (cin a cout)

* V C++ môžete používať funkcie z C na vstup a výstup z konzoly aj súborov. 
* V C++ však existuje aj iný spôsob vstupu a výstupu, ktorý si ukážeme pre konzolu.

```cpp
#include <iostream>
int main() {
    int x, y;
    std::cout << "Zadaj dve cele cisla: ";
    std::cin >> x >> y;
    std::cout << "Suma: " << x + y << std::endl;
}
```

* `cin` je premenná reprezentujúca vstup z konzoly, podobne ako `stdin` v C.
* Pomocou operátora `>>` sa dáta z konzoly načítajú do premenných, načítavanie sa prispôsobuje typu premennej.
* `cout` je premenná reprezentujúca výstup na konzolu, podobne ako `stdout` v C.
* Pomocou operátora `<<` sa dáta z premenných vypíšu na konzolu.
* Ako vidíme vyššie, v jednom príkaze môžeme načítať viacero premenných a vypísať viacero hodnôt.
* Pozor na správny smer operátorov `>>` a `<<`.
* `std::endl` vypíše znak konca riadku (mohli by sme použiť aj `\n`).
* Pri načítaní do premennej typu `char` sa preskakujú biele znaky (medzera, tabulátor, koniec riadku).
* V programoch budeme v zložitejších prípadoch používať `cstdio`, aby sme nemuseli preberať všetky detaily o `cin` a `cout`.

#### String

* V C sme text ukladali ako pole znakov ukončené nulovým znakom.
* V knižnici `string.h` (`cstring`) sú funkcie na prácu s takto uloženým textom.
* Nevýhody však sú, že musíme vopred zvoliť veľkosť poľa a že na porovnávanie a kopírovanie textu musíme používať špeciálne funkcie `strcmp` a `strcpy`.

* V C++ existuje typ `string`, ktorý prácu s textom zjednodušuje.
* Typ `string` je definovaný v knižnici `<string>`.
* Podobne ako pri vektoroch sa nemusíme starať o alokovanie a uvoľňovanie pamäte.
* Reťazce typu `string` môžeme porovnávať pomocou operátorov `==`, `<`, `>` atď., priraďovať pomocou `=` a spájať (zreťazovať, concatenate) pomocou operátora `+`.
* Tieto operácie fungujú dokoca aj medzi reťazcami typu `string` a C-čkovými reťazcami (polia znakov ukončené nulovým znakom).

```cpp
#include <string>
#include <iostream>

int main() {
    char cstr[100] = "Ahoj\n";
    std::string str = "Ako sa mas?\n";
    std::string str2;

    str2 = "Ahoj\n";  // priradenie konštantného Cčkového reťazca
    str2 = cstr;      // priradenie Cčkového reťazca v poli znakov
    str2 = str;       // priradenie iného C++ reťazca  

    // meranie dĺžky reťazca:
    std::cout << "Dlzka je: " << str.length() << std::endl;
}
```
Nasledujúci program načíta jednotlivé slová zo vstupu a uloží ich do vektora reťazcov. Potom ich vypíše na výstup, ale ak za sebou ide niekoľko rovnakých slov, vypíše z nich iba prvé.

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> words;
    std::string word;
    while (std::cin >> word) {
        words.push_back(word);
    }

    for (int i = 0; i < (int)words.size(); i++) {
        if (i == 0 || words[i] != words[i - 1]) {
            std::cout << words[i] << std::endl;
        }
    }
}
```

#### Triedenie

V knižnici `algorithm` sa nachádza veľa funkcií na manipuláciu s poliami a vectormi, napríklad triedenie.

```cpp
#include <algorithm>
#include <vector>
#include <iostream>
#include <cstdlib>

bool customLess(int x, int y) {
    // funkcia vrati true ak |x| < |y|
    return std::abs(x) < std::abs(y);
}

int main() {
    //triedime normalne pole
    int A[6] = {1, -4, 2, 8, 5, 7};
    std::sort(A, A + 6);

    for (int i = 0; i < 6; i++) {
        std::cout << A[i] << " ";
    }
    std::cout << std::endl;

    //triedime vektor
    std::vector <int> B = {1, -4, 2, 8, 5, 7};
    std::sort(B.begin(), B.end());

    for (int i = 0; i < B.size(); i++) {
        std::cout << B[i] << " ";
    }
    std::cout << std::endl;

    // triedime podľa našej porovnávacej funkcie,
    // t.j. podľa absolútnej hodnoty
    std::sort(B.begin(), B.end(), customLess);

    for (int i = 0; i < B.size(); i++) {
        std::cout << B[i] << " ";
    }
    std::cout << std::endl;
}
```

## Smerníky na `struct`

Teraz chvíľu iná téma, ktorá sa nám zíde nabudúce: kombinácia smerníkov a štruktúr (funguje v C aj C++).

* Smerník môže ukazovať aj na `struct`.
* Operátor `.` má vyššiu prioritu ako operátor `*` (dereferencia smerníka).
* Zápis `*s.volaco` je to isté ako `*(s.volaco)` a vyjadruje
  dereferenciu smerníka `s.volaco`.
* Zápis `(*p).volaco` vyjadruje prvok `volaco` štruktúry získanej
  dereferenciou smerníka `p`.
* Zvyčajne je potrebnejší zápis `(*p).volaco`; existuje preňho preto
  skratka `p->volaco`.

```cpp
struct bod {
  int x, y;
};

// ...

bod b; 
b.x = 0;
b.y = 0;
bod *p = &b;       // p ukazuje na bod b

bod *p2 = new bod; // alokovanie nového bodu
(*p2).x = 20;      // bod, na ktorý ukazuje p2, bude mať x 20
p2->y = 10;        // bod, na ktorý ukazuje p2, bude mať y 10
delete p2;         // uvoľnenie pamäte
```

Napríklad nasledujúca funkcia vypočíta stred úsečky medzi bodmi `a` a `b` a uloží ho do bodu `s`, ktorý je odovzdaný do funkcie ako smerník.
```cpp
void stred(bod a, bod b, bod *s) {
    s->x = (a.x + b.x) / 2;
    s->y = (a.y + b.y) / 2;
}
```

Mohli by sme ju zavolať napríklad takto:
```cpp
bod a = {0, 0}, b = {10, 10}, s;
stred(a, b, &s);
```

V C++ by sme namiesto smerníkov mohli použiť referencie:
```cpp
void stred(bod a, bod b, bod &s) {
    s.x = (a.x + b.x) / 2;
    s.y = (a.y + b.y) / 2;
}
// ...

bod a = {0, 0}, b = {10, 10}, s;
stred(a, b, s);
```

## Smerníková aritmetika

Na smerníkoch možno vykonávať určité operácie, ktoré sa zvyknú nazývať
smerníková aritmetika. Uvažujme číslo `n` typu `int` a smerníky `p` a
`q` na nejaký typ `T`.

```cpp
int n;
T *p, *q;
```

  - `p + n` je smerník na `n`-té políčko za adresou `p`, pričom veľkosť
    políčka je daná typom `T`
      - `p + n` je teda to isté ako `&(p[n])` a `*(p+n)` je to isté ako
        `p[n]`.
      - `p++` je skratkou pre `p = p + 1`, posunie nám teda smerník `p`
        o políčko doprava v rámci poľa.
      - Výraz `p[n]` je skratkou pre `*(p + n)`.
      - `p[n]` aj `p + n` teda chceme používať iba ak `p` ukazuje na
        prvok poľa, za ktorým v poli ide ešte aspoň `n` ďalších políčok
  - Podobne `p - n` je smerník na `n`-té políčko pred adresou `p`.
      - `p - n` teda chceme používať iba ak `p` ukazuje na prvok poľa,
        pred ktorým v poli ide ešte aspoň `n` ďalších políčok
  - Ak `p` a `q` sú adresami prvkov v tom istom poli, `p - q` je celé
    číslo `k` také, že `p == q + k`, t.j. o koľko políčok je `p` ďalej
    vpravo od `q`.
  - Ak `p` a `q` sú adresami prvkov v tom istom poli, môžeme ich tiež
    porovnávať pomocou `<, >, <=, >=`
  - Ľubovoľné dva smerníky toho istého typu vieme porovnávať pomocou
    `==, !=`.

Tu je napr. zvláštny spôsob ako vypísať pole `a`:

```cpp
#define N 4

int a[N] = {4, 3, 2, 1};
for (int * smernik = a; smernik < a + N; smernik++) {
     cout << "Prvok " << smernik - a << " je " << *smernik << endl;
}
```

Podobný kód sa ale občas používa na prechádzanie reťazcov. Napríklad
nasledujúca funkcia spočíta počet medzier v reťazci:

```cpp
int zratajMedzery(char str[]) { // mohli by sme dať aj char *str
  int pocet = 0;
  while(*str != 0) {   // kým nenájdeme ukončovaciu nulu
     if(*str == ' ') { // skontroluj znak, na ktorý ukazuje str
         pocet++; 
     }
     str++;           // posuň str na ďalší znak 
  }
  return pocet;
}
```

### Funkcie z knižnice cstring/string.h so smerníkovou aritmetikou

Funkcia `strstr(text, vzorka)` vracia smerník na `char`
- `NULL` ak sa vzorka nenachádza v texte, smerník na začiatok
  prvého výskytu inak
- pozíciu výskytu zistíme smerníkovou aritmetikou:

```cpp
    char *text = "Hello world!";
    char *vzorka = "or";
    char *where = strstr(text, vzorka);
    if(where != NULL) {
      int position = where - text;
    }
 ```

Ako by ste pomocou volaní `strstr` spočítali počet výskytov vzorky v texte?

Podobne `strchr` hľadá prvý výskyt znaku v texte.
