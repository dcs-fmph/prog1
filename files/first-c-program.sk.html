Nainštalujte nástroje (gcc + make) a editory:

sudo apt install build-essential   # gcc, make, libc headre
sudo apt install kate vim nano     # editory
sudo dnf install gcc make          # prekladač + make
sudo dnf install kate vim nano     # editory
sudo pacman -S base-devel          # skupina gcc, make, binutils
sudo pacman -S kate vim nano       # editory

Terminál raz zapnite: Nastavenia → Nastaviť Kate → Terminálový panel (zaškrtnite Automaticky synchronizovať aktuálnu kartu terminálu s aktuálnym dokumentom).
Stlačte F4 (alebo kliknite na ikonu terminálu), potom:

Vysvetlenie príkazu gcc

V príkaze gcc -Wall program.c -o program:

  • -Wall: zapne bežné varovania prekladača; -Wextra pridá ďalšie užitočné.
  • program.c: zdrojový súbor na preklad, zadaný ako argument príkazového riadka.
  • -o program: určuje názov výstupného súboru; bez -o je predvolený názov a.out.

Pridanie matematickej knižnice (-lm)

Zdrojové súbory s <math.h> vyžadujú pri linkovaní na Linuxe matematickú knižnicu. Príklad, uložte ako root.c:

#include <stdio.h>
#include <math.h>
#include <stdlib.h>

int main(int argc, char **argv)
{
    double x = (argc > 1) ? atof(argv[1]) : 16.0;
    printf("sqrt(%.2f) = %.4f\n", x, sqrt(x));
    return 0;
}

Skompilujte s -lm za zdrojovým súborom (linker vyhodnocuje zľava doprava):

gcc -Wall root.c -lm -o root
./root 81          # sqrt(81.00) = 9.0000
gcc -Wall root.c -lm -o root.exe
.\root.exe 81      # sqrt(81.00) = 9.0000
Grafická knižnica SVGdraw

Príprava

  • Stiahnite si knižnicu z example.com.
  • Stiahnuté súbory SVGdraw.cpp a SVGdraw.h uložte do priečinka, v ktorom máte svoje programy.

Working with the SVGdraw graphics library

Keď používate grafickú knižnicu SVGdraw, do vlastného programu na začiatok pridajte riadok #include "SVGdraw.h". 

#include "SVGdraw.h"

int main(void) {
  /* Vytvor obrázok s rozmermi 200x300 pixelov a ulož ho do súboru domcek1.svg */
  SVGdraw drawing;
  SVGdraw_init(&drawing, 200, 300, "domcek1.svg");

  /* Nakresli obdĺžnik (štvorec) s ľavým horným rohom v 50, 150 a šírkou aj dĺžkou 100. */
  SVGdraw_drawRectangle(&drawing, 50, 150, 100, 100);

  /* Prečiarkni štvorec dvomi čiarami po uhlopriečke. */
  SVGdraw_drawLine(&drawing, 50, 250, 150, 150);
  SVGdraw_drawLine(&drawing, 50, 150, 150, 250);

  /* Nakresli strechu ako dve čiary. */
  SVGdraw_drawLine(&drawing, 50, 150, 100, 50);
  SVGdraw_drawLine(&drawing, 150, 150, 100, 50);

  /* Ukonči vypisovanie obrázka. */
  SVGdraw_finish(&drawing);

  return 0;
}

Kompilujte so súborom SVGdraw.c, a nezabudnite pridať prepínač -lm (pretože SVGdraw.c používa math.h):

gcc prog.c SVGdraw.c -lm -o prog
./prog            # .svg obrázok domčeka vytvorený v priečinku vedľa programu
gcc prog.c SVGdraw.c -lm -o prog
.\prog            # .svg obrázok domčeka vytvorený v priečinku vedľa programu

Súbor s príponou .svg si môžete pozrieť napríklad v internetových prehliadačoch Firefox alebo Chromium.
